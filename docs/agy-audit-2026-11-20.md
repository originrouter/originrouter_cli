# agy 全链路复审（2026-11-20）

本轮针对当前未发布源码重新审计。结论以本轮测试、故障注入和代码分析为准；上一次实测结果单独引用，不将历史结果算成本轮重新实测。终端与 App 默认入口继续共用官方原生 TUI + PTY + Hooks，已有 ACP 会话保留其运行时。没有修改 Claude/Codex 的启动分派、网关模型归属或原生配置边界。

App 并行工作区变更撤回后，已重新核对 agy 接入字段、翻译和本轮修复。恢复后的 App 相关回归通过：361 项主链路测试和 74 项补充模型、effort、空会话测试，共 435 项。分析范围没有错误或警告，保留 17 条样式提示。这是相关功能验收，不是完整 App 测试套件通过的声明。

## 本轮发现与修复

| 环节 | 复现的问题 | 修复后的行为 |
| --- | --- | --- |
| 消息中断 | 清空发送中消息时没有保存其不确定送达标记 | 保留不确定 ID，拒绝自动重放；向 App 报告状态 |
| PTY 写入失败 | 异步写入抛错后，发送中消息没有回执定时器，后续队列永久等待 | 结束该发送尝试，标记不确定送达并报告失败 |
| 重复请求 | 已排队消息的重复请求在原生弹窗出现后被误报拒绝 | 先判定已知消息 ID，再检查新消息的输入条件 |
| 消息大小 | 入队没有执行恢复时的长度限制；UTF-8 和附件合并后的大小也未统一约束 | 入队与恢复统一检查字符、UTF-8/JSON 编码大小及 ID，超限不写坏队列 |
| 停止与重启并发 | 配置重启会吞掉被替换子进程的退出通知，也吞掉了期间发生的真实停止 | 同一物理进程只报告一次退出；真实停止正常结束逻辑会话 |
| 替换进程启动失败 | 原进程已经退出，但新进程启动失败时逻辑会话可能仍保持存活 | 报告错误并结束已无可用子进程的会话 |
| 旧进程错误 | 已替换的 PTY 仍可能把错误上报到新进程的会话 | 输出、错误与退出均按进程代次隔离 |
| 执行模式 ACK | 模式已经实际切换，但快照没有保留请求的最终确认；App 对延迟拒绝也缺少通知 | CLI 保留模式 controlResults；App 提示延迟拒绝，本地请求携带关联编号，恢复后回归通过 |
| 输入与中断竞态 | 粘贴文本之后、延迟回车之前收到中断，旧回车仍会提交草稿 | 中断、停止或替换进程使该次待发回车失效 |
| 问题作答与中断 | 原生 Write-in 填写中收到中断，剩余远程按键仍可能落入已取消的界面 | 每次写入和等待均检查原问题仍处于当前会话；中断后不再发送回车或选择按键 |
| 文本中的控制字符 | 普通消息、文本附件可以携带终端控制序列 | 普通聊天输入拒绝控制序列，CRLF 转为 LF；显式终端输入仍使用独立控制入口 |
| 精确恢复 | 模型切换添加精确 conversation 参数时可能保留 `-c` / `--continue` | 精确恢复移除“最近会话”选择器 |
| 工具信息 | 原生/ACP 工具事件及恢复历史没有统一脱敏；带敏感字段的审批未明确标记 | 复用现有有界递归脱敏；审批保留敏感标记，原始执行参数不被修改 |
| Hook 审批异常 | 审批回调抛错后，已拒绝的请求可能继续留在 pending 表里 | 立即拒绝、移除并关闭对应待处理交互 |
| 中文 Hook | HTTP 分块切在 UTF-8 字符中间时会把中文损坏为替代字符 | 累积有界字节后统一解码，保留中文问题及工具参数 |
| 安装锁恢复 | 进程在建锁目录之后、写 owner 文件之前崩溃，可使后续 Hook/MCP 安装永久失败 | 保留新建锁的并发保护；允许回收超过一分钟的无主/损坏锁 |
| App 消息回执 | 队列接受被当成最终送达，稍后的原生拒绝可能丢失附件草稿和失败提示 | 标注 `deliveryState: queued`，App 等待最终回执；失败包含可显示的消息信息 |
| 图片格式 | 原生 agy 只接受已验证的 PNG/JPEG，但 App 仍允许选择 WebP/GIF | 协商具体格式，文件选择器过滤，发送前再次检查并保留草稿 |
| ACP 可选表单 | 全部字段可选的表单仍被强制要求填内容 | 按 schema 的 required 校验，允许提交空对象 |
| 文档 | 代理文档仍声称 App 默认启动 ACP | 已纠正为统一原生链路及保留的显式/历史 ACP |

对应故障、边界和状态机测试位于 `tests/agyAudit.test.js`；App 覆盖排队后拒绝、附件恢复、格式协商、延迟模式拒绝和可选表单。关键故障使用修复前失败、修复后通过的测试复现，包括被切开的真实 HTTP UTF-8 字节和问题作答中断后的多余回车。
